## About
A responsive personal portfolio built with plain HTML, CSS and a little JavaScript.
No frameworks or build step.

## Pages
- `index.html`: About, Skills, Projects, Achievements, Call to Action
- `project-cafeteria.html`: dedicated project details page

## Folder structure
```
portfolio/
├── index.html
├── project-cafeteria.html
├── css/style.css      (colours and fonts are variables at the top)
├── js/main.js         (mobile menu + footer year)
├── assets/            (project screenshots)
└── README.md
```

## How to edit
Search for `EDIT` in `index.html` and `project-cafeteria.html`. Every place you should change has a comment above it.

## Run locally
Open `index.html` in a browser, or use the VS Code "Live Server" extension.
